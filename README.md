# Fighter Jet Assembly (SolidWorks)

A 3D CAD model of a simplified fighter aircraft designed and assembled in **SolidWorks**. The project focuses on parametric part modeling, aircraft structure assembly, and mechanical component integration using standard CAD design practices.

---

## Overview

This project demonstrates the complete workflow of designing individual aircraft components and integrating them into a fully assembled fighter jet model. Each structural component was modeled separately before being assembled using SolidWorks mates and constraints to ensure proper alignment and fit.

The project provided hands-on experience in mechanical CAD modeling, assembly design, and engineering visualization.

---

## Features

- Parametric 3D modeling of aircraft components
- Complete fighter jet assembly in SolidWorks
- Modular component-based design
- Assembly using standard mates and constraints
- Structural alignment and interference-free assembly verification

---

## Components

- Lower Fuselage Plate
- Upper Fuselage Plate
- Main Wing
- Horizontal Stabilizer
- Vertical Stabilizer
